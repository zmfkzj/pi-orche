# Art direction

- Mood: warm embers against cold, wet darkness; hope inside decay.
- Palette (core): soot #2a1d16, umber #3a2a20, ember #e8692a, flame #f2b33d, blood #c0392b, deep water #2e5fa8, mist #a9c6f0.
- In-game sprites and icons: crisp pixel art, 64 px grid, 2 px dark outline (#2a1d16), one highlight on the upper left, no anti-aliasing, transparent background.
- Illustrations (concept art, key art, store art): painterly allowed, same palette, strong silhouettes, ember light as the main light source.
- Typography: chunky serif display type for titles; never thin or script fonts.
- Audience: players of roguelikes such as Hades, Dead Cells and Darkest Dungeon, 18-35.
