# release-tooling

Node rewrite of our Python release helpers. The Python scripts in `scripts/` use three standard-library modules that have no
exact npm equivalent, so each gets a dependency-free port under `src/` (specs in `docs/`). Until all three ports match CPython,
the Python scripts stay authoritative.

- `src/text/` — `textwrap.mjs` and `shlex.mjs` (changelog formatting, command lines in release notes): `docs/text.md`
- `src/difflib/` — `difflib` (API diff reports): `docs/difflib.md`
- `src/urlparse/` — `urllib.parse` (link checker, query building): `docs/urlparse.md`

`node --test` runs the tests. `test/smoke-cases.json` holds sample cases generated by CPython.
